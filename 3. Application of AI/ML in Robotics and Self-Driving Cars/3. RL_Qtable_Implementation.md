# Reinforcement Learning: Q-table Implementation
## Gridworld — Q-Learning 실전 구현

---

## 📌 왜 Gridworld인가?

Gridworld는 강화학습의 핵심 개념을 가장 직관적으로 이해할 수 있는 **표준 벤치마크 환경**이다.
실제 자율주행이나 로봇 내비게이션 문제를 단순화한 것으로,
**상태(State), 행동(Action), 보상(Reward), 정책(Policy)** 의 상호작용을 명확하게 보여준다.

> 복잡한 실제 환경을 다루기 전, 이 예제를 완전히 이해하는 것이 강화학습의 출발점이다.

## 문제 설정 (Problem Setup)

### 환경 구조

```
┌───────┬───────┬───────┬───────┬───────┐
│ Start │       │       │       │       │
├───────┼───────┼───────┼───────┼───────┤
│       │       │       │       │       │
├───────┼───────┼───────┼───────┼───────┤
│       │       │  🟦   │       │       │  ← 장애물 (중앙)
├───────┼───────┼───────┼───────┼───────┤
│       │       │       │       │       │
├───────┼───────┼───────┼───────┼───────┤
│       │       │       │       │  Goal │
└───────┴───────┴───────┴───────┴───────┘
  5 × 5 Grid
```

### 환경 규칙

| 항목 | 내용 |
|------|------|
| **그리드 크기** | 5 × 5 (총 25개 상태) |
| **시작 위치** | 좌상단 (0, 0) |
| **목표 위치** | 우하단 (4, 4) |
| **장애물** | 중앙 (2, 2) |
| **행동 공간** | 상·하·좌·우 (4가지) |

### 보상 체계 (Reward Structure)

| 상황 | 보상 | 의미 |
|------|------|------|
| 목표 도달 | **+1** | 성공 |
| 장애물 충돌 | **-1** | 실패 패널티 |
| 빈 공간 이동 | **0** | 중립 |

> **설계 원칙:** 보상 설계는 강화학습에서 가장 중요한 요소 중 하나다.
> 잘못된 보상 설계는 에이전트가 의도하지 않은 행동을 학습하게 만든다.

## 핵심 구성 요소

### 1. Q-값 테이블 (Q-value Table)

```
Q-table 구조: [행(row), 열(col), 행동(action)] → 3D 배열
크기: 5 × 5 × 4 = 100개의 Q-값
초기값: 모두 0
```

- 각 **상태-행동 쌍 (s, a)** 에 대한 기대 누적 보상을 저장
- 학습이 진행될수록 Q-값이 실제 환경을 반영하여 업데이트됨
- 학습 완료 후, 각 상태에서 **Q-값이 가장 높은 행동 = 최적 행동**

### 2. 엡실론-탐욕 정책 (ε-Greedy Policy)

```
확률 ε       → 탐색 (Exploration): 무작위 행동 선택
확률 (1 - ε) → 활용 (Exploitation): Q-값이 가장 높은 행동 선택
```

| 단계 | ε 값 | 행동 경향 |
|------|------|-----------|
| 학습 초기 | 높음 (예: 1.0) | 탐색 위주 — 환경을 적극적으로 탐험 |
| 학습 중반 | 감소 | 탐색과 활용 균형 |
| 학습 후기 | 낮음 (예: 0.1) | 활용 위주 — 학습된 지식 적극 활용 |

> **핵심 통찰:** ε을 너무 낮추면 지역 최적해(local optimum)에 빠질 수 있다.
> ε을 너무 높이면 학습이 수렴하지 않는다. **적절한 감소 스케줄이 중요하다.**

### 3. Q-값 업데이트 규칙 (Q-Learning Update Rule)

```
Q(s,a) ← Q(s,a) + α [r + γ max_a' Q(s',a') − Q(s,a)]
```

| 구성 요소 | 기호 | 역할 |
|-----------|------|------|
| 현재 Q-값 | Q(s,a) | 상태 s에서 행동 a의 현재 추정값 |
| 학습률 | α | 새로운 정보를 얼마나 반영할지 결정 |
| 즉각 보상 | r | 현재 행동으로 받은 보상 |
| 할인 계수 | γ | 미래 보상의 현재 가치 (0~1) |
| 다음 상태 최대 Q-값 | max Q(s',a') | 다음 상태에서 가능한 최선의 미래 가치 |
| TD 오차 | r + γ max Q(s',a') - Q(s,a) | 예측과 실제의 차이 → 이것이 학습의 원동력 |

## 학습 과정 (Training Process)

```
Q-테이블 초기화 (모든 값 = 0)
         │
         ▼
┌─────── 에피소드 반복 ────────────────────────────┐
│                                                  │
│  시작 위치에서 출발 (0, 0)                        │
│          │                                       │
│          ▼                                       │
│  ε-탐욕 정책으로 행동 선택                        │
│  (탐색: 무작위 / 활용: 최고 Q-값 행동)           │
│          │                                       │
│          ▼                                       │
│  행동 실행 → 다음 상태 s' 도달                   │
│          │                                       │
│          ▼                                       │
│  보상 r 수령                                     │
│  (+1 목표 / -1 장애물 / 0 빈 공간)               │
│          │                                       │
│          ▼                                       │
│  Q-러닝 공식으로 Q(s,a) 업데이트                 │
│          │                                       │
│          ▼                                       │
│  목표 또는 장애물 도달 시 에피소드 종료           │
│                                                  │
└──────────────────────────────────────────────────┘
         │
         ▼
최적 정책 도출 및 시각화
```

## 시각화 출력 (Visualization)

### ① Q-값 히트맵 (Q-values Heatmap)

각 상태의 최대 Q-값을 색상으로 표현한다.

![Q-values Heatmap with Optimal Policy Arrows](Q-values_Heatmap_with_Optimal_Policy_Arrows.png)

```
색상 의미:
  밝은 색 (높은 값) → 목표에 가까운 유리한 상태
  어두운 색 (낮은 값) → 장애물 근처의 불리한 상태
```

| 위치 | Q-값 경향 | 이유 |
|------|-----------|------|
| 목표 근처 | **높음** | 곧 +1 보상을 받을 수 있음 |
| 장애물 근처 | **낮음** | -1 패널티 위험 |
| 시작 위치 | **중간** | 목표까지 여러 단계 필요 |

### ② 학습된 정책 (Learned Policy)

각 상태에서의 최적 행동을 **화살표**로 시각화한다.

```
↓  →  →  →  ↓
↓  →  →  ↑  ↓
↓  →  🟦  ↑  ↓   ← 장애물 우회 경로 학습
↓  →  →  →  ↓
→  →  →  →  ★   ← 목표
```

> 잘 학습된 에이전트는 장애물을 **자동으로 우회**하는 경로를 찾아낸다.
> 이것이 바로 Q-러닝의 핵심 능력이다.

## 결과 해석 (Results Interpretation)

| 결과 | 의미 | 자율주행/로보틱스 관점 |
|------|------|----------------------|
| 히트맵의 값 분포 | 에이전트가 학습한 환경 가치 지도 | 로봇의 위험 지역 인식 |
| 화살표 경로 | 장애물 우회 최적 경로 | 자율주행 경로 계획 |
| 목표 근처 高 Q-값 | 목표 지향적 학습 성공 | 목적지 도달 행동 강화 |
| 장애물 근처 低 Q-값 | 위험 회피 학습 성공 | 충돌 방지 학습 |

## 실제 응용과의 연결

이 단순한 Gridworld 예제는 다음과 같은 실제 문제와 직접적으로 연결된다.

```
Gridworld          →    실제 응용
──────────────────────────────────────────
5×5 그리드         →    실제 도로/작업 공간
시작 → 목표        →    출발지 → 목적지 내비게이션
장애물             →    다른 차량, 보행자, 벽
Q-테이블           →    신경망 (DQN으로 확장)
4가지 행동         →    조향·가속·제동 등 연속 행동
```

> **확장 방향:** 이 Q-테이블 방식은 상태 공간이 커지면 한계에 부딪힌다.
> 이를 해결하기 위해 Q-테이블 대신 **심층 신경망을 사용하는 DQN**으로 발전한다.
