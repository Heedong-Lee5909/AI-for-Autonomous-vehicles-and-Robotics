# Introduction to Reinforcement Learning

---

## 개요
강화학습(RL)은 에이전트가 **누적 보상을 최대화**하기 위해 환경에서 어떻게 행동해야 하는지에 초점을 맞춘 머신러닝의 하위 분야이다.
레이블 데이터로 학습하는 지도 학습과 달리, **환경과의 상호작용(시행착오)** 을 통해 최적의 행동을 학습한다.

---

## 핵심 개념

| 개념 | 기호 | 설명 |
|------|------|------|
| **에이전트** | - | 학습자 또는 의사결정자 |
| **환경** | - | 에이전트가 상호작용하는 모든 것 |
| **상태** | S | 에이전트가 현재 처한 상황의 표현 — 결정에 필요한 모든 정보 포함 |
| **행동** | A | 주어진 상태에서 에이전트가 취할 수 있는 모든 가능한 행동의 집합 |
| **보상** | R | 특정 상태에서 취한 행동의 즉각적인 이익을 나타내는 스칼라 피드백 |
| **정책** | π | 상태 → 행동으로의 전략/매핑 — 에이전트의 행동 결정 |
| **가치 함수** | V 또는 Q | 특정 상태(V(s)) 또는 상태-행동 쌍(Q(s,a))의 기대 누적 보상 추정값 |
| **환경 모델** | - | 다음 상태와 보상을 예측하여 미래 시나리오 시뮬레이션 |

---

## 강화학습 문제

목표: **기대 누적 보상을 최대화**하는 정책 π 찾기

### 탐색-활용 트레이드오프 (Exploration-Exploitation Trade-off)

| 전략 | 설명 |
|------|------|
| **탐색 (Exploration)** | 새로운 행동을 시도하여 그 효과를 발견 |
| **활용 (Exploitation)** | 알려진 정보를 활용하여 보상을 최대화 |

---

## 수학적 프레임워크 — 마르코프 결정 과정 (MDP)

```
MDP = (S, A, T, R, γ)
```

| 구성 요소 | 설명 |
|-----------|------|
| **S** | 상태의 집합 |
| **A** | 행동의 집합 |
| **T** | 전이 함수 — 행동이 주어졌을 때 상태 간 이동 확률 정의 |
| **R** | 보상 함수 |
| **γ ∈ [0,1]** | 할인 계수 — 미래 보상의 가치를 줄여 총 보상 합이 수렴하도록 보장 |

## 핵심 알고리즘

### 1. 모델 프리 방법 (Model-Free Methods)
환경의 명시적 모델을 구축하지 않고 학습한다.

#### 1-1) 가치 기반 방법 (Value-Based Methods)
가치 함수 추정에 초점을 맞춘다.

**Q-러닝 (Q-Learning)**
벨만 방정식을 사용하여 최적 행동-가치 함수 Q(s,a)를 학습한다.
```
Q(s,a) ← Q(s,a) + α [r + γ max_a' Q(s',a') − Q(s,a)]
```

| 구성 요소 | 설명 |
|-----------|------|
| Q(s,a) | 상태 s, 행동 a에 대한 행동-가치 현재 추정값 |
| α | 학습률 (0~1) |
| r | 상태 s에서 행동 a 후 받은 즉각적인 보상 |
| γ | 미래 보상 할인 계수 |
| s' | 행동 a 후의 다음 상태 |
| max_a' Q(s',a') | 상태 s'에서 가능한 모든 행동 중 최대 추정 행동-가치 |

**SARSA (State-Action-Reward-State-Action)**
Q-러닝과 유사하지만 **실제로 취한 행동**을 사용하여 업데이트한다.
```
Q(s,a) ← Q(s,a) + α [r + γ Q(s',a') − Q(s,a)]
```

| 구성 요소 | 설명 |
|-----------|------|
| a' | 현재 정책에 따라 다음 상태 s'에서 실제로 취하는 행동 |

> **Q-러닝 vs SARSA**
> - Q-러닝: 다음 상태에서 **최적 행동**의 가치 사용 → Off-policy
> - SARSA: 다음 상태에서 **실제 취한 행동**의 가치 사용 → On-policy

---

#### 1-2) 정책 기반 방법 (Policy-Based Methods)
정책을 직접 매개변수화하고 최적화한다.

**REINFORCE 알고리즘**
경사 상승법으로 정책 매개변수 θ를 업데이트한다.
```
θ ← θ + α ∇θ log πθ(a|s) Gₜ
```

| 구성 요소 | 설명 |
|-----------|------|
| θ | 정책 함수 πθ의 매개변수 |
| α | 학습률 |
| ∇θ | θ에 대한 기울기 |
| πθ(a\|s) | 정책 πθ 하에서 상태 s에서 행동 a를 취할 확률 |
| log πθ(a\|s) | 정책 확률의 자연 로그 |
| Gₜ | 시간 단계 t부터의 총 할인된 미래 보상: Gₜ = Σ γᵏ rₜ₊ₖ₊₁ |

---

#### 1-3) 액터-크리틱 방법 (Actor-Critic Methods)
가치 기반 + 정책 기반 방법을 **결합**한다.

| 역할 | 설명 |
|------|------|
| **액터 (Actor)** | 크리틱의 평가 방향으로 정책 매개변수 업데이트 |
| **크리틱 (Critic)** | 액터가 취한 행동을 평가하기 위해 가치 함수 추정 |

---

### 2. 모델 기반 방법 (Model-Based Methods)
환경의 모델을 구축하고 계획 수립에 사용한다.

| 방법 | 설명 |
|------|------|
| **동적 프로그래밍 (DP)** | 환경의 완전한 모델 필요, 벨만 방정식을 반복적으로 풀어 해결 |
| **몬테카를로 트리 탐색 (MCTS)** | 결정 공간의 무작위 샘플링 기반으로 탐색 트리 구축 |

## 고급 주제

### 딥 강화학습 (Deep Reinforcement Learning)
신경망을 RL과 결합하여 **고차원 상태 및 행동 공간** 처리

| 방법 | 설명 |
|------|------|
| **딥 Q-네트워크 (DQN)** | 신경망으로 Q-함수 근사 |
| **정책 경사 방법** | 신경망으로 정책 표현, 경사 상승법으로 최적화 |

### 탐색 전략 (Exploration Strategies)

| 전략 | 설명 |
|------|------|
| **ε-탐욕 (ε-Greedy)** | 확률 ε로 무작위 행동, 나머지는 최선의 알려진 행동 선택 |
| **상한 신뢰 구간 (UCB)** | 가치 추정의 불확실성 기반으로 탐색-활용 균형 |

### 시간차 학습 (Temporal Difference Learning)
몬테카를로 방법 + 동적 프로그래밍의 혼합

| 방법 | 설명 |
|------|------|
| **TD(0)** | 연속된 상태의 추정값 차이 기반으로 가치 추정값 업데이트 |
| **TD(λ)** | 적격 트레이스로 여러 미래 단계를 동시에 고려 |

## 강화학습의 과제

| 과제 | 내용 |
|------|------|
| **샘플 효율성** | 환경과의 많은 상호작용 필요 |
| **신용 할당 문제** | 어떤 행동이 미래 보상에 기여했는지 결정 어려움 |
| **희소 보상** | 보상이 드문 환경에서 학습 어려움 |
| **대규모 공간 탐색** | 고차원 공간에서의 효율적 탐색 난제 |
| **안전성과 윤리** | 실제 환경에서 안전하고 윤리적인 행동 보장 필요 |

---

## 미래 방향

| 방향 | 내용 |
|------|------|
| **메타 강화학습** | 에이전트가 학습하는 방법 자체를 학습 → 새로운 작업에 빠르게 적응 |
| **계층적 RL** | 여러 추상화 수준에서 정책 학습 |
| **다중 에이전트 RL** | 여러 학습 에이전트 간의 협력과 경쟁 |
| **전이 학습** | 한 작업의 지식을 다른 작업의 학습에 적용 |

---

## 전체 구조 요약

```
강화학습 (Reinforcement Learning)
│
├── 모델 프리 (Model-Free)
│   ├── 가치 기반 → Q-Learning, SARSA
│   ├── 정책 기반 → REINFORCE
│   └── 액터-크리틱 → Actor + Critic 결합
│
├── 모델 기반 (Model-Based)
│   ├── 동적 프로그래밍 (DP)
│   └── 몬테카를로 트리 탐색 (MCTS)
│
└── 고급 주제
    ├── 딥 강화학습 (DQN 등)
    ├── 탐색 전략 (ε-Greedy, UCB)
    └── 시간차 학습 (TD(0), TD(λ))
```
