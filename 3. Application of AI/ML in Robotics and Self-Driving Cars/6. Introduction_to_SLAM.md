# Introduction to SLAM
## Simultaneous Localization and Mapping

---

## 개요
SLAM은 로봇(또는 자율 시스템)이 **미지의 환경의 지도를 구축하면서 동시에 그 지도 내에서 자신의 위치를 추적**하는 계산 문제이다.
로보틱스, 자율주행차, 증강현실(AR), 가상현실(VR) 시스템의 핵심 기술이다.

### 순환 의존성 — SLAM의 본질적 어려움

```
지도를 만들려면 → 자신의 위치를 알아야 한다
자신의 위치를 알려면 → 지도가 있어야 한다
```

> 이 **순환 의존성**이 SLAM을 어렵게 만드는 동시에,
> 자율 시스템에 있어 반드시 해결해야 할 핵심 과제로 만든다.

---

## SLAM이 중요한 이유

| 분야 | 필요성 |
|------|--------|
| **자율주행차** | 사전 지도 없이 미지의 도로를 탐색 |
| **로보틱스** | 드론·로봇·산업기계가 동적·미지 환경에서 운용 |
| **AR/VR** | 실시간 환경 이해로 사용자와의 자연스러운 상호작용 |
| **탐사** | GPS가 없는 행성 탐사, 수중 탐색 등에 활용 |

---

## SLAM의 핵심 목표

SLAM이 추정해야 하는 두 가지:

| 추정 대상 | 수식 | 설명 |
|-----------|------|------|
| **로봇의 자세 (Pose)** | xₜ = [xₜ, yₜ, θₜ] | 위치 (x, y)와 방향 θ |
| **지도 (Map)** | m = {f₁, f₂, ..., fₙ} | 랜드마크·장애물 등의 환경 표현 |

```
입력 (Input):  센서 측정값 + 제어 입력
출력 (Output): 환경 지도 + 지도 내 로봇 위치 추정값
```

**전체 SLAM 상태:**
```
sₜ = [xₜ, m]
```

## SLAM의 주요 과제

| 과제 | 내용 |
|------|------|
| **불확실성** | 센서 측정값의 노이즈, 로봇 움직임의 불확실성 |
| **데이터 연관** | 어떤 측정값이 지도의 어떤 특징에 해당하는지 식별 |
| **비선형성** | 로봇의 움직임과 센서 모델이 비선형인 경우가 많음 |
| **루프 클로저** | 이전에 방문한 장소로 돌아왔을 때 이를 감지하여 오차 수정 |
| **실시간 제약** | 제한된 계산 자원에서 실시간으로 효율적으로 실행 필요 |

## SLAM의 종류

### 1. 센서 기반 분류

| 종류 | 센서 | 특징 |
|------|------|------|
| **Visual SLAM (vSLAM)** | 카메라 | 단안(Monocular), 스테레오, RGB-D 방식 |
| **LiDAR SLAM** | LiDAR | 정밀한 3D 거리 측정, 높은 정확도 |
| **RGB-D SLAM** | RGB 카메라 + 깊이 센서 | 시각·깊이 정보 동시 수집 |
| **다중 센서 SLAM** | 카메라+LiDAR+IMU+GPS | 견고한 지도 작성 및 위치 추정 |

### 2. 지도 표현 방식 기반 분류

| 종류 | 표현 방식 | 활용 |
|------|-----------|------|
| **특징 기반 SLAM** | 희소 랜드마크 집합 (점, 모서리 등) | 계산 효율적, 실시간 처리에 적합 |
| **격자 기반 SLAM** | 점유 격자 (각 셀에 점유 확률 저장) | LiDAR SLAM에 주로 사용 |
| **밀집 SLAM** | 환경의 모든 표면·텍스처를 밀집 연속 지도로 표현 | AR/VR, 고화질 매핑 |

### 3. 알고리즘 기반 분류

| 알고리즘 | 특징 | 적합한 환경 |
|----------|------|-------------|
| **EKF SLAM** | 가우스 분포로 불확실성 표현, 칼만 필터 기반 | 선형에 가까운 환경 |
| **파티클 필터 (FastSLAM)** | 다수의 입자로 다양한 가설 표현 | 비선형·다중 모달 분포 |
| **그래프 기반 SLAM** | 그래프 최적화 문제로 모델링 | 대규모 환경, 장기 탐색 |
| **밀집 SLAM (ORB-SLAM 등)** | 밀집 3D 지도 재구성 | 시각 기반 고화질 매핑 |

## 수학적 프레임워크

### 1. 베이즈 SLAM 프레임워크

SLAM은 **확률적 추론 문제**로 형식화된다.

**목표:** 센서 측정값과 제어 입력이 주어졌을 때, 로봇의 궤적과 지도에 대한 사후 분포 계산
```
p(x₀:ₜ, m | z₁:ₜ, u₁:ₜ)
```

| 구성 요소 | 설명 |
|-----------|------|
| x₀:ₜ | 시간 t까지의 로봇 궤적 |
| m | 환경의 지도 |
| z₁:ₜ | 시간 t까지의 모든 센서 측정값 |
| u₁:ₜ | 시간 t까지의 모든 제어 입력 (예: 주행 거리계) |

### 2. SLAM 핵심 두 단계 (재귀적 반복)

**예측 단계 — 동작 모델 (Motion Model):**
```
xₜ = f(xₜ₋₁, uₜ) + wₜ
```
- f: 동작 모델 / wₜ: 프로세스 노이즈

**업데이트 단계 — 측정 모델 (Measurement Model):**
```
zₜ = h(xₜ, m) + vₜ
```
- h: 관측 모델 / vₜ: 측정 노이즈

## 주요 SLAM 알고리즘 상세

### 1. EKF SLAM (확장 칼만 필터 SLAM)

가장 먼저 개발되고 널리 사용된 SLAM 접근 방식이다.
가우스 노이즈를 가정하고 야코비안(Jacobian)을 사용한 1차 테일러 전개로 비선형성을 선형화한다.

**① 상태 예측:**
```
xₜ = Fₜ xₜ₋₁ + Bₜ uₜ + wₜ
```

**② 공분산 예측:**
```
Pₜ = Fₜ Pₜ₋₁ Fₜᵀ + Qₜ
```

**③ 칼만 이득 계산:**
```
Kₜ = Pₜ Hₜᵀ (Hₜ Pₜ Hₜᵀ + Rₜ)⁻¹
```

**④ 상태 업데이트:**
```
xₜ = xₜ + Kₜ(zₜ − Hₜ xₜ)
```

**⑤ 공분산 업데이트:**
```
Pₜ = (I − Kₜ Hₜ) Pₜ
```

| 구성 요소 | 설명 |
|-----------|------|
| xₜ | 시간 t에서 로봇의 위치·방향 및 랜드마크 위치를 포함한 상태 벡터 |
| Fₜ | 상태 전이 행렬 — 이전 상태와 제어 입력 기반으로 상태 변화 모델링 |
| Bₜ | 제어 입력 행렬 — 제어 입력(속도, 조향각)이 상태에 미치는 영향 매핑 |
| uₜ | 제어 입력 벡터 (속도 vₜ, 조향각 ωₜ 등) |
| wₜ | 프로세스 노이즈 — 공분산 Qₜ의 영평균 가우스 노이즈 |
| Qₜ | 프로세스 노이즈 공분산 — 동작 모델의 불확실성 |
| Pₜ | 예측 공분산 행렬 — 로봇 자세와 랜드마크 위치의 불확실성 |
| Kₜ | 칼만 이득 — 예측 대비 측정값의 신뢰도 가중치 결정 |
| Hₜ | 관측 행렬 — 예측 상태를 측정 공간으로 매핑 |
| Rₜ | 측정 노이즈 공분산 — 센서 측정의 불확실성 |
| zₜ | 측정 벡터 — 실제 센서 측정값 |
| (zₜ − Hₜ xₜ) | 혁신 (Innovation) — 실제 측정값과 예측 측정값의 차이 |

### 2. 파티클 필터 SLAM (FastSLAM)

EKF보다 **비선형성과 다중 모달 분포**를 더 잘 처리한다.

```
FastSLAM 3단계:

① 예측 (Prediction)
   각 입자 = 가능한 로봇 자세
   동작 모델 기반으로 각 입자의 위치 업데이트

② 수정 (Correction)
   각 입자가 측정 모델로 자신의 지도 업데이트
   랜드마크와 관측 특징 연관

③ 재샘플링 (Resampling)
   중요도 가중치 기반으로 입자 재샘플링
   데이터를 잘 설명하는 입자 생존
   설명력 낮은 입자 제거
```

---

### 3. 그래프 기반 SLAM (Graph-Based SLAM)

SLAM을 **그래프 최적화 문제**로 모델링한다.

```
그래프 구조:
  노드 (Nodes) → 로봇 자세 및 랜드마크 위치
  엣지 (Edges) → 센서 측정값 또는 주행 거리계 기반 제약 조건
```

```
Graph-Based SLAM 2단계:

① 그래프 구성 (Graph Construction)
   각 노드: 로봇 자세 또는 랜드마크
   각 엣지: 측정값(제약 조건)

② 오차 최소화 (Error Minimization)
   예측 측정값과 실제 측정값의 오차를 최소화하는
   최적 자세·랜드마크 구성 탐색
   (Gauss-Newton 또는 Levenberg-Marquardt 최적화)
```

> 대규모 환경 표현과 장기간 궤적 최적화에 효과적 → **현대 응용에서 가장 널리 사용**

---

### 4. 밀집 SLAM (Dense SLAM)

환경의 **밀집 3D 지도 재구성**을 목표로 한다.

| 시스템 | 방식 | 특징 |
|--------|------|------|
| **ORB-SLAM** | 단안·스테레오 Visual SLAM | ORB 특징으로 추적·지도작성·루프클로저 수행 |
| **LSD-SLAM** | 직접 단안 SLAM | 특징 추출 없이 픽셀 강도를 직접 최소화하여 반밀집 3D 지도 구축 |

## 핵심 개념

### 데이터 연관 (Data Association)
어떤 측정값이 지도의 어떤 랜드마크·특징에 해당하는지 결정하는 과정이다.
올바른 데이터 연관은 정확한 지도 구축과 오류 방지의 핵심이다.

### 루프 클로저 (Loop Closure)
로봇이 이전에 탐색한 위치를 **다시 방문했을 때 이를 감지**하는 것이다.
루프 클로저를 감지하면 축적된 위치 추정 오차를 수정하고 지도 정확도를 향상시킨다.

### 지도 최적화 (Map Optimization)
예측 측정값과 실제 측정값 사이의 오차를 최소화하도록 **지도와 로봇 궤적을 조정**하는 과정이다.
그래프 기반 SLAM에서 특히 중요하다.

## SLAM 응용 분야

| 분야 | 활용 사례 |
|------|-----------|
| **자율주행차** | 실시간 장애물 감지 및 안전 주행 — LiDAR SLAM (정밀), Visual SLAM (저비용) |
| **로보틱스** | 드론·로봇청소기·산업 로봇이 GPS 없이 미지 환경 탐색·지도 작성 |
| **AR/VR** | 사용자 움직임 실시간 추적, 가상 요소의 현실 세계 오버레이 (ARKit, ARCore) |
| **지도 작성·측량** | 건물·터널·고고학 현장의 3D 지도 생성 (GPS 불필요) |
| **탐사** | 수중·지하·우주 탐사 — GPS 불가 환경에서 자율 탐색 및 지도 작성 |

## 알고리즘 비교 요약

| 알고리즘 | 장점 | 단점 | 주요 사용처 |
|----------|------|------|-------------|
| **EKF SLAM** | 수학적으로 잘 정립됨 | 계산 복잡도 O(n²), 비선형성 취약 | 소규모, 구조화된 환경 |
| **FastSLAM** | 비선형·다중 모달 처리 우수 | 입자 수 증가 시 계산 부하 | 비선형 동적 환경 |
| **그래프 기반 SLAM** | 대규모 환경, 정확한 최적화 | 후처리 최적화 필요 | 현대 자율주행·로보틱스 |
| **밀집 SLAM** | 고화질 3D 지도 | 높은 계산 자원 필요 | AR/VR, 고정밀 매핑 |

## 전체 SLAM 흐름

```
센서 입력 (LiDAR / 카메라 / IMU / GPS)
         │
         ▼
┌─────── SLAM 재귀 루프 ──────────────────────┐
│                                             │
│  ① 예측 단계 (동작 모델)                    │
│     xₜ = f(xₜ₋₁, uₜ) + wₜ                │
│                                             │
│  ② 데이터 연관                              │
│     측정값 ↔ 랜드마크 매핑                  │
│                                             │
│  ③ 업데이트 단계 (측정 모델)                │
│     zₜ = h(xₜ, m) + vₜ                    │
│                                             │
│  ④ 루프 클로저 감지                         │
│     이전 방문 장소 재인식 → 오차 수정       │
│                                             │
│  ⑤ 지도 최적화                              │
│     그래프 최적화 / 공분산 업데이트         │
│                                             │
└─────────────────────────────────────────────┘
         │
         ▼
정확한 지도 + 로봇 위치 추정
```
