# Regional Convolutional Neural Networks (R-CNN)

---

## 개요
R-CNN은 컴퓨터 비전 분야에서 **물체 감지(Object Detection)** 의 획기적인 발전을 나타낸다.
이미지 분류(Classification)와 물체 감지(Detection) 사이의 간극을 연결하여,
이미지 내 물체를 **정확하게 위치 추정(Localization)하고 분류**하는 것을 가능하게 했다.

> R-CNN은 이후 Fast R-CNN, Faster R-CNN, Mask R-CNN으로 이어지는
> 현대 물체 감지 모델 계보의 **시작점**이다.

---

## R-CNN의 탄생 배경

### 기존 방식의 한계
기존 슬라이딩 윈도우(Sliding Window) 기법:
- 이미지 내 수많은 위치와 크기에서 분류기를 실행 → **계산 비용이 매우 큼**

### R-CNN의 핵심 동기

| 목표 | 내용 |
|------|------|
| **효율성** | 후보 영역을 좁혀 계산 부담 감소 |
| **정확도** | CNN의 강력한 특징 추출 및 분류 능력 활용 |
| **확장성** | 다양한 물체 클래스와 복잡한 이미지 처리 가능 |

---

## R-CNN의 4가지 핵심 구성 요소

```
입력 이미지
    │
    ▼
① 영역 제안 생성 (Selective Search)
   ~2,000개의 후보 영역 추출
    │
    ▼
② CNN 특징 추출
   각 영역을 227×227로 변환 후 CNN 처리
   → 4096차원 특징 벡터
    │
    ▼
③ SVM 분류
   클래스별 이진 SVM으로 물체 분류
    │
    ▼
④ 경계 박스 회귀
   예측 박스를 정밀하게 조정
    │
    ▼
NMS (비최대 억제)로 중복 박스 제거
    │
    ▼
최종 감지 결과
```

---

## 1. 영역 제안 생성 (Region Proposal Generation)

**선택적 탐색 (Selective Search)** 알고리즘으로 이미지당 약 2,000개의 고품질 후보 영역을 생성한다.

### Selective Search 3단계

```
Step 1: 슈퍼픽셀 생성 (Superpixel Generation)
  └── Felzenszwalb 방법으로 유사한 색상·텍스처의 픽셀을 소규모 영역으로 분할

Step 2: 영역 계층 구조 생성 (Region Hierarchy Creation)
  └── 색상·텍스처·크기·형태 유사도 기준으로 슈퍼픽셀을 재귀적으로 병합

Step 3: 영역 제안 추출 (Region Proposal Extraction)
  └── 다양한 크기와 종횡비의 후보 영역 집합 출력
      → 다양한 스케일의 물체 포착
```

### Selective Search의 장점

| 장점 | 내용 |
|------|------|
| **효율성** | 수백만 개의 윈도우 → 수천 개로 탐색 공간 축소 |
| **품질** | 높은 물체 재현율(Recall)의 제안 생성 |

---

## 2. CNN 특징 추출 (Feature Extraction Using CNNs)

각 영역 제안을 개별적으로 CNN에 통과시켜 특징을 추출한다.

### 처리 과정

| 단계 | 내용 |
|------|------|
| **정규화** | 각 영역을 227×227 픽셀로 변환 (CNN 입력 크기 통일) |
| **CNN 아키텍처** | ImageNet으로 사전 학습된 AlexNet 주로 사용 |
| **특징 추출** | FC7 레이어에서 4096차원 특징 벡터 출력 |

### 수학적 표현
```
fᵢ = CNN(Rᵢ; θ)
```

| 기호 | 설명 |
|------|------|
| fᵢ | 영역 Rᵢ의 특징 벡터 |
| CNN | 합성곱 신경망 함수 |
| Rᵢ | 변환된 영역 제안 |
| θ | CNN의 가중치 및 편향 파라미터 |

---

## 3. SVM 분류 (Classification Using SVMs)

추출된 특징 벡터로 클래스별 이진 SVM 분류기를 학습한다.

### 학습 데이터 구성

| 구분 | 조건 | 의미 |
|------|------|------|
| **양성 예제** | IoU > 0.5 (실제 박스와 50% 이상 겹침) | 해당 클래스의 물체 |
| **음성 예제** | IoU < 0.3 (실제 박스와 30% 미만 겹침) | 배경 |

### 결정 함수 수식
```
sᵢᶜ = wᶜᵀ fᵢ + bᶜ
```

| 기호 | 설명 |
|------|------|
| sᵢᶜ | 영역 Rᵢ가 클래스 c에 속할 점수 |
| wᶜ | 클래스 c SVM의 가중치 벡터 |
| bᶜ | 클래스 c SVM의 편향 항 |
| fᵢ | 영역 Rᵢ의 특징 벡터 |

---

## 4. 경계 박스 회귀 (Bounding Box Regression)

예측된 경계 박스를 **실제 박스에 더 가깝게 정밀하게 조정**한다.

### 목표 오프셋 (Target Offsets)

영역 제안 좌표 (x, y, w, h)와 실제 박스 (x*, y*, w*, h*)가 주어질 때:

```
tₓ = (x* − x) / w
tᵧ = (y* − y) / h
tᵥ = log(w* / w)
t_h = log(h* / h)
```

### 정제된 박스 좌표 예측
```
x' = x + w · Δx
y' = y + h · Δy
w' = w · e^(Δw)
h' = h · e^(Δh)
```

| 기호 | 설명 |
|------|------|
| x, y | 영역 제안의 중심 좌표 |
| w, h | 영역 제안의 너비와 높이 |
| x*, y*, w*, h* | 실제 박스의 해당 파라미터 |
| tₓ, tᵧ, tᵥ, t_h | 필요한 조정값을 나타내는 회귀 목표 |

### 손실 함수 — Smooth L1 Loss
```
L_reg(tᵢ, tᵢ*) = Σⱼ smooth_L1(tᵢʲ − tᵢʲ*)

smooth_L1(x) = { 0.5x²      if |x| < 1
               { |x| − 0.5  otherwise
```

| 기호 | 설명 |
|------|------|
| L_reg | 회귀 손실 |
| tᵢ | 영역 i의 예측 오프셋 |
| tᵢ* | 영역 i의 실제 오프셋 |
| j | x, y, w, h 좌표 인덱스 |

> **Smooth L1 Loss를 사용하는 이유:**
> 오차가 작을 때는 L2처럼, 클 때는 L1처럼 동작하여
> 이상값(Outlier)에 강건하면서 수렴도 안정적이다.

## 학습 절차 (Training Procedure)

R-CNN 학습은 **4단계 다중 단계 프로세스**로 이루어진다.

```
① CNN 사전 학습 (Pretraining)
   ImageNet으로 분류 학습 → 좋은 특징 표현 초기화
        │
        ▼
② CNN 파인튜닝 (Fine-tuning)
   영역 제안으로 물체 감지에 맞게 재학습
   각 영역: 물체 클래스 또는 배경으로 레이블링
        │
        ▼
③ SVM 학습 (Training SVMs)
   CNN에서 추출한 특징 벡터로 클래스별 이진 SVM 학습
        │
        ▼
④ 경계 박스 회귀기 학습 (Training Regressors)
   CNN 특징으로 클래스별 선형 회귀 모델 학습
```

### 학습의 주의사항

| 항목 | 내용 |
|------|------|
| **다단계 프로세스** | CNN·SVM·회귀기를 각각 별도로 학습 → 복잡성 증가 |
| **데이터 처리** | 양성·음성 예제의 신중한 준비 및 균형 필요 |
| **계산 시간** | 각 영역 제안을 CNN에 개별 통과 → 시간 소요 큼 |

---

## 테스트 및 추론 (Testing & Inference)

```
① 영역 제안 생성: Selective Search로 후보 영역 추출
        │
        ▼
② 특징 추출: 각 영역을 227×227로 변환 후 CNN 통과
        │
        ▼
③ SVM 분류: 각 영역의 클래스 분류 및 점수 계산
        │
        ▼
④ 경계 박스 회귀: 예측 박스 정밀 조정
        │
        ▼
⑤ NMS (비최대 억제, Non-Maximum Suppression)
   - 감지 박스를 점수 내림차순으로 정렬
   - 최고 점수 박스 선택
   - IoU > 임계값(예: 0.3)인 겹치는 박스 제거
   - 남은 박스로 반복
```

## R-CNN의 한계 (Limitations)

| 한계 | 내용 |
|------|------|
| **계산 비효율성** | ~2,000개 영역을 각각 CNN에 통과 → 막대한 계산 오버헤드 |
| **저장 요구량** | 추출된 특징을 디스크에 캐싱 → 대용량 저장 공간 필요 |
| **다단계 학습** | CNN·SVM·회귀기 별도 학습 → 파이프라인 복잡성 증가 |
| **느린 추론** | 실시간 처리 불가 → 실제 응용 한계 |

## R-CNN 계보 — 개선 모델들

| 모델 | 핵심 개선 | 성능 |
|------|-----------|------|
| **R-CNN** | 영역 제안 + CNN 결합 | 높은 정확도, 느린 속도 |
| **Fast R-CNN** | 이미지 전체를 한 번만 CNN 처리 (RoI Pooling) | 훨씬 빠른 학습·추론 |
| **Faster R-CNN** | RPN으로 영역 제안 자동화, 완전 통합 네트워크 | 실시간에 가까운 속도 |
| **Mask R-CNN** | 인스턴스 분할 브랜치 추가 (RoIAlign) | 물체 감지 + 마스크 예측 |

### Fast R-CNN 주요 개선

- **공유 계산:** 전체 이미지를 한 번 처리하여 공유 특징 맵 생성
- **RoI Pooling:** 공유 특징 맵에서 각 영역의 고정 크기 특징 추출
- **단일 단계 학습:** 분류와 경계 박스 회귀를 하나의 네트워크로 통합

### Faster R-CNN 주요 개선

- **RPN (Region Proposal Network):** Selective Search 대신 신경망으로 영역 제안 자동 생성
- **완전 통합 아키텍처:** RPN + Fast R-CNN 통합
- **실시간 성능:** 거의 실시간 물체 감지 속도 달성

### Mask R-CNN 주요 개선

- **인스턴스 분할:** 물체 마스크 예측 브랜치 추가
- **RoIAlign:** 양자화 오류 방지로 더 정확한 마스크 예측

## 핵심 개념 정리

| 개념 | 설명 |
|------|------|
| **IoU (Intersection over Union)** | 예측 박스와 실제 박스의 겹침 비율 — 감지 품질 평가 지표 |
| **NMS (Non-Maximum Suppression)** | 중복 감지 박스 제거 알고리즘 |
| **RoI (Region of Interest)** | 관심 영역 — 특징 추출의 대상이 되는 후보 영역 |
| **Selective Search** | 영역 제안 생성 알고리즘 |
| **Smooth L1 Loss** | 이상값에 강건한 회귀 손실 함수 |

## R-CNN의 의의

```
R-CNN의 기여
├── 딥러닝을 물체 감지에 성공적으로 적용한 최초의 방법
├── PASCAL VOC에서 당시 최고 성능 달성
├── Fast R-CNN → Faster R-CNN → Mask R-CNN으로 이어지는 계보의 시작
└── 현대 자율주행·의료·보안 분야 물체 감지 기술의 기초
```

> **R-CNN을 이해하는 것은 현대 물체 감지 아키텍처의 진화를 이해하고,
> 지속적으로 영향을 미치는 기초 개념을 파악하는 데 필수적이다.**
