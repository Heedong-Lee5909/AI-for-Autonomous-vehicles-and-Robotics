# Algorithms in Self-Driving Cars

---

## 개요
자율주행차는 복잡한 알고리즘의 조합으로 구현된 교통 분야의 혁명적인 발전이다.
기능에 따라 **인식 → 위치 추정 → 경로 계획 → 제어 → 의사결정 → 통신** 으로 분류된다.

---

## 1. 인식 (Perception)

인식은 자율주행 기술의 **기반**으로, 물체 감지, 의미론적 분할, 센서 융합으로 이루어진다.

### 1-1) 물체 감지 (Object Detection)
CNN을 사용하여 보행자, 차량, 교통 표지판 등을 실시간으로 감지·분류한다.

| 알고리즘 | 방식 | 특징 |
|----------|------|------|
| **YOLO** | 전체 이미지를 한 번에 처리 | 실시간 다중 물체 감지 |
| **R-CNN** (영역 기반 CNN) | 관심 영역 식별 후 CNN 적용 | 높은 정확도의 분류 |

### 1-2) 의미론적 분할 (Semantic Segmentation)
이미지의 각 **픽셀을 분류**하여 도로, 보도, 장애물 등을 구분한다.

| 알고리즘 | 특징 |
|----------|------|
| **DeepLab** | 픽셀 단위 정밀 분류 |
| **U-Net** | 픽셀 단위 분류, 의료·도로 이미지에 활용 |

> 분할된 이미지에서 보행자, 보도, 도로, 차량 등이 서로 다른 색상으로 표시됨
> → 픽셀 수준의 이해로 복잡한 환경 탐색 가능

### 1-3) 센서 융합 (Sensor Fusion)
LiDAR, 레이더, 카메라 등 **여러 센서의 데이터를 결합**하여 정확한 환경 모델 생성

| 필터 | 방식 |
|------|------|
| **칼만 필터** | 시스템 상태와 불확실성을 추적, 예측·업데이트 반복으로 상태 추정 정교화 |
| **파티클 필터** | 가중 입자들로 사후 분포를 근사화, 우도 함수 기반 가중치 업데이트 및 리샘플링 |

---

## 2. 위치 추정 및 지도 작성 (Localization & Mapping)

환경을 이해한 후, 해당 공간 내에서 차량의 **정확한 위치**를 파악한다.

### 2-1) SLAM (동시 위치 추정 및 지도 작성)
주변 환경의 지도를 구축·업데이트하면서 동시에 그 지도 내 자신의 위치 결정

| 방식 | 특징 |
|------|------|
| **확장 칼만 필터 SLAM** | 실시간 지도 작성 및 위치 추적 |
| **그래프 기반 SLAM** | 도로를 노드로 분할, XYZ 평면에서 정밀한 2.5D LiDAR 지도 생성 |

### 2-2) 몬테카를로 위치 추정 (MCL, Monte Carlo Localization)
- 확률적 접근 방식으로 여러 위치 가설을 유지하며 차량 위치 추정
- 차량이 이동하고 새로운 데이터를 수집할수록 추정값이 점점 정교해짐
- **파티클 필터** 사용: 파란색 입자들이 이동하면서 단일 위치로 수렴

### 2-3) 시각적 주행 거리 측정 (Visual Odometry)
카메라 이미지로 프레임 간 시각적 특징을 추적하여 차량의 움직임 추정

| 알고리즘 | 특징 |
|----------|------|
| **ORB-SLAM** | 카메라 기반 특징 추적 |
| **스테레오 비전** | 두 카메라로 깊이 정보 추정 |

> GPS 신호가 불안정한 환경에서 특히 중요

---

## 3. 경로 계획 (Path Planning)

차량이 따를 **가장 안전하고 효율적인 경로**를 결정한다.

### 3-1) 전역 경로 계획 (Global Path Planning)
현재 위치에서 목적지까지의 최단 경로 계산

| 알고리즘 | 방식 |
|----------|------|
| **A*** | 휴리스틱으로 탐색 최적화 |
| **Dijkstra** | 모든 가능한 경로 탐색 → 최단 경로 보장 |

### 3-2) 지역 경로 계획 (Local Path Planning)
실시간으로 장애물을 피하며 동적 환경에 대응

| 알고리즘 | 특징 |
|----------|------|
| **RRT** (급속 탐색 무작위 트리) | 고차원 공간에서 실시간 장애물 회피 |
| **DWA** (동적 창 접근법) | 실시간 충돌 회피, 전역 경로 유지 |

### 3-3) 궤도 최적화 (Trajectory Optimization)
- **모델 예측 제어 (MPC):** 미래 상태를 예측하고 경로를 지속적으로 최적화
- 복잡한 시나리오에서 부드럽고 안전하며 효율적인 주행 보장

---

## 4. 제어 (Control)

계획된 경로를 실행하기 위해 **조향, 가속, 제동**을 관리한다.

| 알고리즘 | 방식 | 활용 |
|----------|------|------|
| **PID 제어** | 원하는 궤도와 실제 경로의 오차 최소화 | 차선 유지, 속도 조절 |
| **LQR** (선형 이차 조절기) | 비용 함수 최소화로 차량 역학 최적화 | 부드럽고 안정적인 주행 |
| **ACC** (적응형 순항 제어) | 레이더·카메라로 앞 차량과의 거리 유지 | 고속도로 주행 |

---

## 5. 의사결정 (Decision Making)

다양한 주행 시나리오에서 **차량의 반응 방식**을 결정한다.

| 알고리즘 | 방식 | 활용 |
|----------|------|------|
| **유한 상태 기계 (FSM)** | 상황에 따라 주행 모드 전환 | 차선 변경, 추월, 정지 |
| **마르코프 결정 과정 (MDP)** | 확률적 상태 전이 기반 의사결정 | 복잡한 주행 행동 관리 |
| **딥 Q-네트워크 (DQN)** | 강화학습 — 보상 기반 시행착오로 최적 전략 학습 | 복잡하고 동적인 환경 |

---

## 6. 통신 (Communication)

자율주행차가 **주변 환경 및 다른 차량과 상호작용**할 수 있게 한다.

### V2X (Vehicle-to-Everything, 차량-사물 통신)
- 차량 ↔ 다른 차량, 인프라, 보행자 간 통신 지원
- 협력적인 움직임으로 사고 위험 감소 및 교통 흐름 개선

---

## 전체 알고리즘 구조 요약

```
센서 데이터 입력
      │
      ▼
① 인식 (Perception)
   물체 감지 → 의미론적 분할 → 센서 융합
      │
      ▼
② 위치 추정 (Localization & Mapping)
   SLAM / MCL / Visual Odometry
      │
      ▼
③ 경로 계획 (Path Planning)
   전역 계획 (A*, Dijkstra) → 지역 계획 (RRT, DWA) → 궤도 최적화 (MPC)
      │
      ▼
④ 제어 (Control)
   PID / LQR / ACC
      │
      ▼
⑤ 의사결정 (Decision Making)
   FSM / MDP / DQN
      │
      ▼
⑥ 통신 (Communication)
   V2X
```
