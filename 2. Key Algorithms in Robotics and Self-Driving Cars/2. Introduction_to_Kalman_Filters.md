# Introduction to Kalman Filters

---

## 개요
칼만 필터는 불완전하고 노이즈가 있는 일련의 측정값으로부터 **동적 시스템의 상태를 추정**하는 강력한 수학적 도구이다.
평균 제곱 오차를 최소화하는 방식으로 프로세스의 상태를 효율적으로 추정(재귀적 계산)한다.
이론의 주요 개발자인 **루돌프 E. 칼만(Rudolf E. Kálmán)**의 이름을 따서 명명되었다.

---

## 핵심 개념

### 상태 공간 표현 (State-Space Representation)

칼만 필터는 **선형 확률적 차분 방정식**으로 설명되는 프로세스의 내부 상태를 추정한다.

**상태 방정식 (프로세스 모델):**
```
xₖ = Fₖ xₖ₋₁ + Bₖ uₖ + wₖ₋₁
```

**측정 방정식 (관측 모델):**
```
zₖ = Hₖ xₖ + vₖ
```

| 구성 요소 | 설명 |
|-----------|------|
| xₖ | 시간 단계 k에서의 상태 벡터 (예: 위치 및 속도) |
| Fₖ | 상태 전이 행렬 — 시간 k−1의 상태가 시간 k에 미치는 영향 |
| Bₖ | 제어 입력 행렬 — 각 제어 입력 파라미터의 영향 적용 |
| uₖ | 제어 입력 벡터 (예: 가속도 명령) |
| wₖ₋₁ | 프로세스 노이즈 벡터 (평균 0, 공분산 Qₖ₋₁의 가우스 분포) |
| zₖ | 시간 k에서의 측정 벡터 |
| Hₖ | 관측 행렬 — 실제 상태 공간을 관측 공간으로 매핑 |
| vₖ | 측정 노이즈 벡터 (평균 0, 공분산 Rₖ의 가우스 분포) |

---

### 가정 (Assumptions)

| 가정 | 내용 |
|------|------|
| **선형성** | 시스템 동역학 및 측정 방정식이 선형 |
| **가우스 노이즈** | 프로세스 노이즈와 측정 노이즈 모두 백색(비상관), 가우스 분포, 평균 0 |
| **초기 조건** | 초기 상태 x₀와 공분산 P₀은 알려진 값 |

---

## 칼만 필터 알고리즘

알고리즘은 **두 단계로 재귀적**으로 작동한다.

```
┌─────────────────────────────────────┐
│          예측 단계 (Prediction)      │
│  이전 상태로부터 현재 상태 예측       │
└──────────────────┬──────────────────┘
                   │
                   ▼
┌─────────────────────────────────────┐
│          업데이트 단계 (Update)      │
│  실제 측정값으로 예측값 보정         │
└──────────────────┬──────────────────┘
                   │
                   ▼
              (반복 순환)
```

---

### 1단계: 예측 단계 (Prediction Step)

**예측 상태 추정:**
```
x̂ₖ|ₖ₋₁ = Fₖ x̂ₖ₋₁|ₖ₋₁ + Bₖ uₖ
```

**예측 추정 공분산:**
```
Pₖ|ₖ₋₁ = Fₖ Pₖ₋₁|ₖ₋₁ Fₖᵀ + Qₖ₋₁
```

| 구성 요소 | 설명 |
|-----------|------|
| x̂ₖ|ₖ₋₁ | k−1 시간까지의 관측을 바탕으로 한 시간 k의 예측 상태 추정값 |
| x̂ₖ₋₁|ₖ₋₁ | 시간 k−1에서의 업데이트된 상태 추정값 |
| Pₖ|ₖ₋₁ | 시간 k에서의 예측 추정 공분산 |
| Pₖ₋₁|ₖ₋₁ | 시간 k−1에서의 업데이트된 추정 공분산 |
| Qₖ₋₁ | 프로세스 노이즈 공분산 행렬 |

> **핵심:** 상태 전이 행렬 Fₖ와 제어 입력 uₖ로 다음 상태를 예측하고, 이전 공분산과 프로세스 노이즈를 합산하여 불확실성을 반영한다.

---

### 2단계: 업데이트 단계 (Update Step)

**① 혁신(잔차) 계산 — 실제 측정값과 예측값의 차이:**
```
yₖ = zₖ − Hₖ x̂ₖ|ₖ₋₁
```

**② 혁신 공분산:**
```
Sₖ = Hₖ Pₖ|ₖ₋₁ Hₖᵀ + Rₖ
```

**③ 칼만 이득 (Kalman Gain):**
```
Kₖ = Pₖ|ₖ₋₁ Hₖᵀ Sₖ⁻¹
```

**④ 업데이트된 상태 추정:**
```
x̂ₖ|ₖ = x̂ₖ|ₖ₋₁ + Kₖ yₖ
```

**⑤ 업데이트된 추정 공분산:**
```
Pₖ|ₖ = (I − Kₖ Hₖ) Pₖ|ₖ₋₁
```

| 구성 요소 | 설명 |
|-----------|------|
| yₖ | 시간 k에서의 혁신 또는 측정 잔차 |
| Sₖ | 혁신 공분산 행렬 |
| Kₖ | 칼만 이득 행렬 |
| x̂ₖ|ₖ | 시간 k에서의 업데이트된 상태 추정값 |
| Pₖ|ₖ | 시간 k에서의 업데이트된 추정 공분산 행렬 |
| I | 단위 행렬 |
| Rₖ | 측정 노이즈 공분산 행렬 |

---

## 각 단계 상세 설명

### 예측 단계
- **상태 예측:** 상태 전이 행렬 Fₖ와 제어 입력 uₖ를 사용하여 예측 상태 추정값 x̂ₖ|ₖ₋₁ 계산
- **공분산 예측:** 이전 추정 공분산과 프로세스 노이즈 공분산 Qₖ₋₁의 불확실성을 통합하여 Pₖ|ₖ₋₁ 계산

### 업데이트 단계
- **혁신:** 실제 측정값 zₖ와 예측 측정값 Hₖ x̂ₖ|ₖ₋₁ 사이의 불일치를 나타냄
- **혁신 공분산:** 예측 추정 공분산 + 측정 노이즈 공분산을 결합한 예상 불확실성 반영
- **칼만 이득:** 예측 추정값과 측정값 사이의 불확실성을 균형 있게 조정하여 혁신의 가중치 결정
- **상태 업데이트:** 가중된 혁신으로 예측 상태 추정값을 보정
- **공분산 업데이트:** 측정값 반영 후 감소된 불확실성을 나타냄

---

## 칼만 이득의 수학적 유도

칼만 이득 Kₖ는 **사후 추정 공분산 Pₖ|ₖ를 최소화**하여 도출되며, 평균 제곱 오차를 최소화하는 최적 이득이다.

**목표 — Kₖ에 대해 Pₖ|ₖ를 최소화:**
```
Pₖ|ₖ = (I − Kₖ Hₖ) Pₖ|ₖ₋₁ (I − Kₖ Hₖ)ᵀ + Kₖ Rₖ Kₖᵀ
```

**해 — Pₖ|ₖ의 Kₖ에 대한 도함수를 0으로 설정:**
```
Kₖ = Pₖ|ₖ₋₁ Hₖᵀ (Hₖ Pₖ|ₖ₋₁ Hₖᵀ + Rₖ)⁻¹
```
