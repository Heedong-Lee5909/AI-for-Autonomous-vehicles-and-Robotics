# Algorithms in Robotics

---

## 개요
로봇 시스템은 고급 알고리즘의 개발과 적용 덕분에 크게 발전했다.
이러한 알고리즘들은 불확실한 환경 탐색부터 정밀한 물체 조작까지 로봇이 스스로 복잡한 작업을 수행할 수 있게 한다.

### 5가지 핵심 알고리즘 분야
1. 내비게이션 및 경로 계획 (Navigation & Path Planning)
2. 로봇 조작 (Robot Manipulation)
3. 위치 추정 및 지도 작성 (Localization & Mapping)
4. 머신러닝 알고리즘 (Machine Learning Algorithms)
5. 군집 로봇 알고리즘 (Swarm Robotics Algorithms)

---

## 1. 내비게이션 및 경로 계획 (Navigation & Path Planning)

특히 동적이거나 미지의 환경에서 로보틱스의 근본적인 과제이다.

### SLAM (동시 위치 추정 및 지도 작성)
- 자율 주행에 필수적인 알고리즘
- 로봇이 자신의 위치를 추적하면서 **동시에** 주변 환경의 지도를 생성
- LiDAR, 카메라 등의 센서 데이터를 결합하여 상세한 지도 작성

### 경로 계획 알고리즘

| 알고리즘 | 특징 | 적합한 환경 |
|----------|------|-------------|
| **A*** | 이동 비용과 목표까지의 거리를 균형있게 고려하는 휴리스틱 기반 탐색 | 일반적인 환경 |
| **Dijkstra** | 가능한 모든 경로를 탐색하여 최단 경로 결정 | 완전히 지도화된 환경 |
| **D* Lite** | A*를 확장하여 환경 변화에 따라 경로 실시간 업데이트 | 동적 환경, 실시간 내비게이션 |
| **RRT** (급속 탐색 무작위 트리) | 고차원 공간에서 충돌 회피 동작 계획 | 로봇 팔 등 고차원 공간 |
| **PRM** (확률적 로드맵) | 확률적 방식으로 경로 탐색, 충돌 회피 | 로봇 팔 등 고차원 공간 |

## 2. 로봇 조작 (Robot Manipulation)

로봇 팔과 그리퍼의 정밀한 제어에 초점을 맞추며, 정확성·효율성·적응력을 보장한다.

### 역기구학 (Inverse Kinematics)
- 원하는 위치와 방향에 끝 작동기(End Effector)를 위치시키는 데 필요한 **관절 각도 계산**
- 용접, 조립, 도장 작업에 핵심적으로 사용

### 궤도 계획 (Trajectory Planning)
- 속도, 가속도, 장애물 등을 고려하여 최적의 경로 계산
- **스플라인 기반 궤도 계획:** 연속적이고 부드러운 움직임 보장
  - 주황색 선: 보간 없는 곡선
  - 파란색 선: 스플라인 보간을 사용한 부드러운 곡선

### 파지 계획 (Grasp Planning)
- 센서 데이터와 머신러닝으로 물체의 형태·크기·재질에 따라 최적의 파지 방법 결정
- 로봇이 그립을 **동적으로 조정** 가능

**파지 계획의 2단계 프로세스:**

```
1단계: 파지 기술 인식
  └─ 인간 시연을 기반으로 손 접촉 위치 및 접근 방향 인식

2단계: 파지 합성 (최적화)
  └─ 그리퍼 손가락이 물체 표면에 밀착되도록 조정
  └─ 충돌 여부 확인
  └─ 충돌 발생 시 → 안전 위치로 이동 후 최적화 재시작
```

## 3. 위치 추정 및 지도 작성 (Localization & Mapping)

### 위치 추정 (Localization)

| 필터 | 특징 | 적합한 환경 |
|------|------|-------------|
| **칼만 필터 (Kalman Filter)** | 센서 노이즈를 걸러내어 정확한 위치 추정 | 선형, 가우스 환경 |
| **파티클 필터 (Particle Filter)** | 확률적 접근 방식 사용 | 비선형, 비가우스 환경 |

> SLAM → 미지의 환경 / 칼만·파티클 필터 → 이미 알려진 환경

### 지도 작성 (Mapping)
- **점유 격자 지도 (Occupancy Grid Mapping)**
  - 환경을 격자 형태의 셀로 표현
  - 각 셀은 장애물이 차지할 가능성을 나타냄
  - 검은색 셀: 장애물 점유 / 흰색 셀: 빈 공간
  - 실내외 복잡한 환경의 내비게이션과 계획에 필수적

## 4. 머신러닝 알고리즘 (Machine Learning Algorithms)

인식, 의사결정, 적응성 측면에서 로보틱스를 발전시키는 핵심 기술이다.

| 알고리즘 | 설명 | 주요 활용 |
|----------|------|-----------|
| **강화학습 (Reinforcement Learning)** | 환경과 상호작용하며 보상 기반으로 행동 최적화 | 동적 환경에서의 복잡한 작업 |
| **합성곱 신경망 (CNN)** | 시각 데이터 처리, 물체 인식 및 환경 해석 | 자율주행, 물체 감지, 장면 이해 |
| **모방 학습 (Imitation Learning)** | 인간 시연을 관찰하여 작업 학습 | 서비스 로봇, 인간 유사 행동 |
| **비지도 학습 (Unsupervised Learning)** | 패턴 식별 및 비정상 사건 감지 | 불확실하거나 예측 불가능한 환경 |
| **이상 탐지 (Anomaly Detection)** | 비정상적인 이벤트 감지 | 안전한 자율 운행 |

## 5. 군집 로봇 알고리즘 (Swarm Robotics Algorithms)

여러 로봇이 협력하여 공동 목표를 달성하는 분산 지능 시스템이다.

### 합의 알고리즘 (Consensus Algorithms)
- 군집 내 여러 로봇이 방향, 작업 배분 등의 파라미터에 **합의**하도록 보장
- 중앙 집중식 제어 없이 효율적인 협력 가능

### 보이드 알고리즘 (Boids Algorithm)
- 새의 무리 행동에서 영감을 받은 알고리즘
- 군집 내 로봇의 집단적 움직임 관리
- **중앙 집중식 제어 없이** 조율된 행동 달성
